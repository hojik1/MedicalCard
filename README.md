# Медицинская карта пациента

## Описание проекта

Проект представляет собой систему управления медицинскими картами пациентов. Программа реализована на Java 21 и состоит из библиотеки классов, описывающих предметную область, и консольного приложения для демонстрации её возможностей.

## Модель предметной области

В проекте реализованы следующие сущности:

- **Patient** — пациент. Содержит номер страхового полиса и ФИО. Равенство пациентов определяется по номеру полиса.
- **Doctor** — врач. Содержит идентификатор, ФИО и медицинскую специальность.
- **Appointment** — запись пациента на приём к врачу с указанием даты и времени.
- **Diagnosis** — диагноз пациента, поставленный врачом.
- **Prescription** — назначение врача с периодом действия.
- **Specialty** — перечисление медицинских специальностей. Для каждой специальности определены номер кабинета и продолжительность приёма.
- **MedicalRecordEntry** — интерфейс для записей медицинской карты. Реализуется классами `Diagnosis` и `Prescription`.

## Реализованные возможности

Программа поддерживает базовые операции:

1. Запись пациента на приём к врачу.
2. Проверка занятости врача и кабинета.
3. Проверка рабочего времени кабинета.
4. Получение истории приёмов пациента за указанный период.
5. Добавление диагнозов.
6. Добавление назначений.
7. Поиск действующих назначений пациента на определённую дату.
8. Обработка попыток записи на занятое время с помощью собственного исключения `AppointmentConflictException`.

Рабочее время кабинетов в демонстрационной реализации: с 08:00 до 20:00.

## Запуск проекта

Для сборки проекта и запуска тестов необходимо выполнить:

```bash
mvn test
```

Для сборки проекта:

```bash
mvn package
```

Для запуска консольного приложения после сборки:

```bash
java -cp target/classes ru.vsu.cs.Main
```

Также приложение можно запустить непосредственно из IntelliJ IDEA через метод `main` класса `Main`.

## Тестирование

Для проверки корректности работы программы используются модульные тесты JUnit 5.

Тесты проверяют:
- создание объектов и обработку некорректных данных;
- равенство пациентов и соответствие контракту `equals/hashCode`;
- проверку занятости врача и кабинета;
- обработку конфликтов при записи;
- поиск действующих назначений;
- обработку граничных случаев и исключений.

## Демонстрация

Консольное приложение создаёт более 30 объектов предметной области и последовательно демонстрирует основные операции системы с выводом результатов в консоль.
